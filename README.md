# AstraGov AI - 3D Interactive AI Government Exam Mock Test Platform

A cutting-edge, 3D interactive web platform for government exam aspirants (UPSC Civil Services, SSC CGL, IBPS/SBI Bank PO, RRB NTPC Railways, and State PSCs) featuring real-time AI analytics, 3D WebGL visualizations, adaptive test generation, and 24/7 AI mentoring.

---

## 🌟 Key Features

### 1. Interactive 3D WebGL Neural Core (Three.js)
- **Central AI Reactor**: Pulsating icosahedron core, holographic wireframe cage, and 3-axis gyroscopic tech rings.
- **Orbital Exam Satellites**: Floating 3D geometrical subject nodes (Polity, History, Economics, Quant, Science, Reasoning) revolving around the core.
- **Interactive Mouse Controls**: Parallax camera tilts, drag-to-rotate orbital physics, and clickable 3D nodes that highlight syllabus domains.
- **Visual Modes**: Toggle on-the-fly between **Quantum**, **Matrix**, and **Holo** 3D styles.

### 2. High-Precision Exam Simulator (NTA / TCS-iON Pattern)
- **Countdown Timer**: Real-time timer with color-coded warning indicators and auto-submit.
- **Official Question Status Palette**:
  - 🟢 **Answered** (Green)
  - 🔴 **Not Answered** (Red)
  - 🟣 **Marked for Review** (Purple)
  - 🔵 **Answered & Marked for Review** (Cyan with badge)
  - ⚪ **Not Visited** (Gray)
- **Elimination & Strike Tool**: Cross out obvious wrong options (A, B, C, D) just like on real physical exam papers!
- **AI Strategic Hints**: Get high-level conceptual hints and mnemonic clues without spoiling the exact answer.
- **Adjustable Text Size**: Seamless A- / A / A+ font scaling.

### 3. Generative AI Test Architect
- Synthesize custom mock tests on any topic (e.g. *"Articles 12-35 Fundamental Rights"*, *"Repo Rate & Monetary Policy"*, *"Train Speed & Distance"*).
- Configure difficulty (Easy, Medium, Hard, UPSC Standard) and question quantity (5, 10, 15).

### 4. 24/7 AI Exam Mentor & Doubt Solver ("Astra AI")
- Integrated slide-out drawer to ask any conceptual doubt, formula, or shortcut trick.
- Pre-loaded with instant mnemonics like *"TEARS OF OLD PM"* for Constitution Schedules, *Writ of Quo-Warranto*, and *Compound Interest Speed Hacks*.

### 5. AI Post-Exam Diagnostic Scorecard
- **All India Rank (AIR) Predictor**: Calibrated percentile and simulated All India Rank.
- **Negative Penalty Impact**: Calculates exact marks deducted for wrong attempts.
- **Subject-Wise Precision Radar**: Visual breakdown of your strengths vs remedial topics.
- **Detailed Solution Review**: Complete conceptual breakdown, elimination rationale, mnemonic shortcuts, and standard reference textbook citations for every question.

### 6. Procedural Audio Synthesis (Web Audio API)
- High-tech synthetic sound feedback for button clicks, option selections, countdown warnings, and test completion—zero external MP3 files needed!

## 🚀 How to Run

1. Open `index.html` in any modern web browser (Google Chrome, Microsoft Edge, Brave, Firefox, Safari).
2. Or use any local static server:
   ```bash
   npx serve .
   # or
   python -m http.server 8080
   ```
3. Click **"Take Official Mock Test"** to begin practicing immediately!
